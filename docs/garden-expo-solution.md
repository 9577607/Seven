# 园林展会 H5 + 微信小程序 + 后台管理系统（设计方案）

## 1. 项目定位

- **项目名称**：园林展会 H5 + 微信小程序 + 后台管理系统
- **目标用户**：园林爱好者、设计师、游客、主办方运营人员
- **核心目标**：
  - 用户端提供「资讯浏览 + 活动参与 + 作品投稿 + 个人中心」闭环。
  - 管理端提供「内容配置 + 审核流程 + 用户运营 + 数据分析」能力。
  - 系统具备后续扩展到商城、预约、票务营销等业务的基础。

## 2. 技术架构设计

### 2.1 技术栈（与需求对齐）

- **前端**：Uni-app（同构输出 H5 + 微信小程序）
- **后台管理端**：Vue 3 + Element Plus（建议），统一调用 Spring Boot API
- **后端**：Java 17 + Spring Boot 3.x + Spring Security + MyBatis-Plus（或 JPA）
- **数据库**：MySQL 8.0
- **缓存**：Redis（登录态、验证码、热点数据缓存、限流）
- **对象存储**：阿里云 OSS / 腾讯云 COS（图片/视频）
- **消息队列**：RabbitMQ（投稿审核通知、统计异步任务）
- **部署**：阿里云 ECS + Nginx + Docker Compose（可平滑升级为 K8s）

### 2.2 分层架构

1. **接入层**：Nginx（HTTPS、静态资源、反向代理）
2. **应用层**：
   - `miniapp-api`：小程序/H5 业务接口
   - `admin-api`：管理后台接口
   - `job-worker`：统计聚合、通知、数据清洗任务
3. **数据层**：MySQL + Redis + OSS/COS
4. **运维层**：Prometheus + Grafana + ELK（可选）

### 2.3 模块边界

- **用户侧模块**：首页、活动、投稿、个人中心、电子票券
- **管理侧模块**：权限、内容、投稿审核、奖项配置、用户管理、统计看板
- **公共能力模块**：文件上传、字典配置、审计日志、消息通知

## 3. 用户端功能设计（Uni-app）

### 3.1 首页

- 顶部 Banner 轮播：支持后台配置排序、启停、跳转链接。
- 地图模块：展示园林景点静态地图图层（可后续升级为腾讯地图 SDK）。
- 主题活动区：卡片入口（春季花展、园林讲座、园林科普、植物科普）。
- 底部导航：首页 / 投稿 / 个人中心。

#### 页面接口建议

- `GET /api/app/home/config`：一次性返回 Banner、地图、活动卡片。
- `GET /api/app/activities`：活动列表。
- `GET /api/app/activities/{id}`：活动详情。

### 3.2 投稿页

- 顶部 Banner：可由后台活动配置动态替换。
- 四个功能模块：
  1. 投稿说明（弹窗或图文页）
  2. 作品上传入口（图片/视频 + 标题 + 描述 + 分类）
  3. 奖项设置展示（后台配置）
  4. 截止时间（日期或倒计时）
- 投稿能力增强：
  - 最多 9 张图片，支持压缩后上传 OSS/COS
  - 文字描述、投稿类型下拉（后台可维护）
  - 提交后状态默认 `PENDING`
  - 个人中心可查看进度（待审核/通过/驳回/需修改）

#### 页面接口建议

- `GET /api/app/submission/config`：投稿须知、奖项、截止时间、分类选项
- `POST /api/app/upload/presign`：获取直传签名
- `POST /api/app/submissions`：提交投稿
- `GET /api/app/submissions/my`：我的投稿列表
- `GET /api/app/submissions/{id}`：投稿详情

### 3.3 个人中心

- 头像、昵称、个性签名（可编辑）。
- 入场券模块：点击领取生成电子券（二维码/条形码），支持核销状态。
- 我的投稿：缩略图网格 + 投稿数量统计。

#### 页面接口建议

- `GET /api/app/user/profile`
- `PUT /api/app/user/profile`
- `POST /api/app/tickets/claim`：领券
- `GET /api/app/tickets/my`：查看票券
- `POST /api/app/tickets/verify`：核销（运营端/抖音活动场景可走开放平台回调）

## 4. 管理后台功能设计（Web）

### 4.1 登录与权限管理

- 账号密码登录 + JWT + 刷新 Token。
- RBAC 角色：
  - 超级管理员
  - 内容编辑
  - 审核员
  - 数据分析师
- 审计日志：记录登录、增删改、审核动作、导出行为。

### 4.2 内容管理

- Banner 管理：上传、排序、启用/禁用。
- 活动管理：创建/编辑/上下架，包含封面、标题、简介、跳转。
- 地图管理：维护景点地图静态图。
- 分类字典：投稿类型增删改查（如园林设计、花卉盆景）。

### 4.3 投稿管理

- 投稿列表：按作者、分类、状态、时间筛选。
- 审核流程：通过/拒绝/打回修改（理由必填）。
- 奖项配置：名称、数量、奖品、评选标准。
- 截止时间：全局或按活动维度配置。

### 4.4 用户管理

- 用户列表：openid、昵称、头像、注册时间、最近活跃时间。
- 入场券记录：领取时间、使用状态、核销人、核销时间。

### 4.5 数据统计看板

- 投稿总数、日新增投稿、通过率。
- 活跃用户数（DAU/WAU）。
- 活动参与人数、热门作品排行。
- 趋势图：7 日/30 日。

## 5. 数据库模型（MySQL）

核心表建议：

- `sys_user`：后台用户
- `sys_role` / `sys_user_role` / `sys_permission`：权限模型
- `app_user`：小程序用户
- `content_banner`：Banner 配置
- `content_activity`：活动配置
- `content_map`：地图图层/图片
- `submission`：投稿主表
- `submission_media`：投稿素材（多图/视频）
- `submission_category`：投稿分类字典
- `submission_audit_log`：审核日志
- `award_config`：奖项配置
- `ticket`：电子入场券
- `ticket_verify_log`：核销记录
- `op_log`：后台操作日志
- `stat_daily`：日统计快照

> 详细建表示例见 `db/garden_expo_schema.sql`。

## 6. 关键流程设计

### 6.1 投稿流程

1. 用户进入投稿页，拉取配置（分类/奖项/截止时间）
2. 客户端直传图片到 OSS/COS
3. 提交投稿表单，状态为 `PENDING`
4. 审核员后台处理：`APPROVED` / `REJECTED` / `RETURNED`
5. 审核结果通过订阅消息/站内消息通知用户

### 6.2 入场券流程

1. 用户点击“立即领取”
2. 生成唯一票券码 + 二维码内容（可签名防篡改）
3. 入场核销时校验状态（未使用、未过期）
4. 核销成功后更新 `USED` 并记录日志

## 7. 性能与并发方案

### 7.1 指标目标

- 页面加载 < 2 秒（首屏）
- 支持并发 5000 用户访问（峰值）

### 7.2 实施策略

- 首页配置接口聚合返回，减少请求数。
- 图片采用 CDN + WebP + 小程序压缩上传。
- Redis 缓存热点数据（Banner、活动、奖项、分类）。
- 投稿/统计使用异步任务解耦。
- 数据库优化：
  - 高频查询字段加索引（状态、时间、活动 ID、用户 ID）
  - 分页查询 + 覆盖索引
  - 慢 SQL 监控与治理
- 压测建议：JMeter / k6，验证 5000 并发下 P95 响应。

## 8. 安全设计

- 全链路 HTTPS。
- Spring Security + JWT + 接口鉴权。
- 参数校验 + 预编译防 SQL 注入。
- XSS 过滤与上传文件白名单（MIME + 后缀）。
- 敏感操作二次验证（如批量审核、配置下发）。
- 管理员登录失败次数限制 + 图形验证码。
- 审计日志不可篡改（可定期归档到对象存储）。

## 9. 兼容性与可维护性

- 微信 iOS/Android 主流版本兼容（基础库分级测试）。
- 统一 API 错误码规范与 OpenAPI 文档。
- 模块化代码组织（controller/service/repository/domain）。
- 关键逻辑补充单元测试 + 集成测试。
- 提供部署文档、备份恢复文档、巡检清单。

## 10. 可扩展能力预留

- 预留商城模块：商品、订单、支付。
- 预留预约模块：时段库存、预约核销。
- 预留营销模块：优惠券、积分、裂变活动。
- 预留第三方接入：抖音/公众号/企业微信。

## 11. 里程碑建议（12 周）

- **第 1-2 周**：需求冻结、原型与数据库设计
- **第 3-5 周**：用户端核心页面 + 后端基础能力
- **第 6-8 周**：后台管理、审核流、票券核销
- **第 9-10 周**：统计看板、性能优化、安全加固
- **第 11-12 周**：联调、压测、灰度、上线
